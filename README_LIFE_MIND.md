# Medora Life Mind Planner

This layer upgrades Planner from a simple task list into a guided long-term planning system.

Current live features:
- ready-made plans for fitness, walking, languages, Quran, prayer, congregational worship, Sadaqah, Zakah planning, helping people, music and travel
- daily or selected-day routines
- 30/60/90 day, 12-week, 6-month and 1-year durations
- one-tap Done / Partly / Not done check-ins
- congregation bonus points without changing compliance above 100%
- compliance calculation from scheduled occurrences
- Medora guidance based on consistency
- private, accountability and together modes
- shared-plan comparison
- browser due-time reminders while the app/PWA is running

Background push while the app is completely closed needs a push subscription + scheduled backend delivery layer and is intentionally not claimed as completed here.
